─────────────────────────────────────────────────────
📦 デプロイパッケージ作成コマンド
─────────────────────────────────────────────────────

./scripts/package-deploy.sh

または手動で:

tar -czf deploy.tar.gz \
  app/ components/ lib/ types/ \
  prisma/schema.prisma prisma/migrations/ prisma/seed.ts \
  package.json package-lock.json \
  tsconfig.json next.config.js tailwind.config.js postcss.config.js \
  character_masters_export.json

─────────────────────────────────────────────────────
📤 サーバーへの転送
─────────────────────────────────────────────────────

# SCP
scp deploy.tar.gz user@server:/path/

# rsync（推奨）
rsync -avz --exclude='node_modules' --exclude='.next' \
  --exclude='.env' --exclude='*.db' \
  . user@server:/path/

# Git（最推奨）
git push origin main
# サーバー上で: git pull

─────────────────────────────────────────────────────
🔧 サーバー上でのセットアップ
─────────────────────────────────────────────────────

# 1. 環境変数設定
cp .env.example .env.production
nano .env.production

# 2. セットアップ
npm ci
npx prisma generate
npx prisma migrate deploy
npm run seed  # 初回のみ

# 3. ビルド
npm run build

# 4. 起動
npm start
# または
pm2 start npm --name monstdb -- start

─────────────────────────────────────────────────────

.next（ビルド後）:     ~50 MB（サーバーでビルド）

合計転送サイズ:        ~625 KB（非常に軽量！）
